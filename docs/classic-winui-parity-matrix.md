# Classic → WinUI 3 完整迁移矩阵

本文件是 WinUI 3 迁移的强制范围与验收基准。Classic 的当前可达界面、仍由兼容类保留的能力，以及实际交互行为都必须进入原生 WinUI 3；“打开 Classic”不计为功能对等。

## 实施状态

- 最终发布身份已锁定为 `v0.9.6.8c`；只有本矩阵要求和前台验收完成后才创建该发布。
- 第一批已实施：WinUI 根页面恢复 Classic 的菜单/工具栏、Frames、预览/直方图、右侧六标签和底部状态栏结构。
- 根页面已经拆为 `ClassicCommandStrip`、`ClassicFramesPane`、`ClassicPreviewPane`、`ClassicProcessingTabs`，并由 `MainPage` 只负责组装与页面级选择器。
- 帧队列、异步缩略图、堆栈分组、独立素材命名、CPU/GPU 自检、任务进度与取消继续复用现有拆分视图模型和服务。
- Classic 兼容启动器已从 WinUI 工程移除；后续缺失能力必须原生补齐，不允许以启动 Tk 代替。
- 第二批已实施：六参数页按职责拆分，现有处理模型的拉伸、基础调色、细节、通道和曲线参数均可通过原生滑块、数值框和双击复位操作。
- 节点导出已增加单一前置条件检查与可见原因；去闪、曝光平滑、白平衡平滑不再参与按钮可用性状态机。
- H.264 已采用桌面硬件解码安全的闭合短 GOP、无 B 帧、单参考帧，并按 UHD 帧率选择正确 Level。
- WinUI 发布脚本已禁止混入 Classic/venv/site-packages，并设置 750 MiB 解压体积预算；引擎从 436.0 MiB 降至 352.7 MiB，同时 RTX 4060/CuPy 自检仍通过并自动选择 GPU。
- 主工作区帧预览已迁至 Python 子进程异步解码，返回最高 2048 边长代理与 64 档真实亮度直方图；快速切帧会丢弃过期结果。
- RGB/红/绿/蓝/亮度曲线已迁为原生交互画布，支持添加、拖动、右键删除、端点保护和单通道/全部复位；真实控制点直接进入 IPC。
- 节点点击已按 Stack、Stretch、Base、BGR、USM、High Pass、Emboss、Channel、Output 分派专用编辑器，不再统一打开整套大参数面板。
- 第三批已实施：曝光/白平衡工作区已按帧表、预览和调整面板拆分，支持异步全帧分析、关键帧编辑/向导/同步/重置、过渡重建、再次平滑、ROI、修正预览和取消；同一锚点配置会回写节点批量导出。
- Classic 主菜单的文件/项目、帧选择、处理页导航、预览适应、主题、性能/存储信息和关于已接入原生操作。
- Classic 撤销/重做现已覆盖处理参数、开关和多通道曲线控制点；Auto Stretch 是不修改源数据的异步显示代理。
- 堆栈任务已增加 IPC 级暂停/继续与“使用当前结果”控制，在安全帧边界生效并保留已累计帧。
- 字体、主题和中英文菜单设置可即时应用并持久化；不改变 Classic 的控件位置与面板结构。
- 关键帧页已增加低分辨率播放路径、FPS/时间线、原始/修正/左右对比、虚拟化缩略图带，以及曝光/色温/色调的原始、平滑和关键帧目标趋势曲线。
- 尚待真实前台验收：自包含 Release 的拖窗、缩放、滚动和 Stack/Timelapse 切换帧时间。
- `v0.9.6.8c` 成品自动导航烟雾测试：页面复用全部通过，稳定采样约 240 FPS、平均 4.17 ms、P95 4.41 ms、卡顿帧 0；该结果不替代鼠标前台拖窗视觉验收。

## 迁移原则

- 保留 Classic 的信息架构、控件顺序、面板比例、术语和操作路径，不重新设计工作流。
- Python 继续作为图像算法与批处理引擎；WinUI 只承载原生窗口、状态、输入与绘制。
- 预览、缩略图、直方图和进度更新不得阻塞 UI 线程。
- 页面、控件、视图模型、服务和协议按职责拆分；禁止产生上千行的新单文件。
- 只有本矩阵所有“必须”项通过自动测试与真实前台验收后，才能移除 Classic 兼容入口并标记迁移完成。

## A. Classic 主窗口（必须）

### A1. 顶部菜单

- 文件：添加图片/RAW、添加文件夹、打开单图编辑、保存当前图像、清空工程、退出。
- 编辑：撤销、重做、全选帧、移除所选帧。
- 堆栈：开始、暂停/继续、使用当前结果并停止、取消。
- 延时：打开堆栈延时。
- 线性处理：Auto Stretch 预览、Asinh 拉伸入口。
- 调整：基础调整、通道混合器。
- 滤镜：USM、高反差保留、浮雕、曲线。
- 视图：Auto Stretch、适合窗口。
- 设置：界面字体、主题、语言、界面设置。
- 帮助：堆栈与性能说明、存储与缓存管理、关于。

### A2. 主工具栏与三栏工作区

- 工具栏：RAW/图片、文件夹、开始堆栈、堆栈延时、暂停、使用当前、Auto Stretch、撤销、重做、导出。
- 左栏：Frames 顺序列表、选择、多选、移除、计数。
- 中栏：预览导航、25/50/100/200%、Fit、缩放、平移、图像预览、Histogram。
- 右栏固定六页：堆栈、拉伸、基础、细节、通道、曲线。
- 底部：任务状态、图像状态（LINEAR/NONLINEAR）、进度与可取消状态。

### A3. 堆栈页

- Mean/Maximum。
- 起始帧、结束帧、使用当前选择范围。
- 曝光归一化。
- 32-bit float TIFF Master 输出。
- CPU/自动/NVIDIA CUDA、自检、RAW 并行解码数、内存预算与策略。
- 实时堆栈预览、暂停/继续、使用当前结果、取消。

### A4. 调色与滤镜页

- 拉伸：Asinh Strength、Black Point、应用与恢复 Linear Master。
- 基础：Basic、WB、Presence、HSL、八色 Color Mixer、Color Grading、Detail、Optics、Calibration。
- 细节：USM、High Pass、High Pass 曲线、Emboss 类型/角度圆盘/高度/数量/混合/不透明度。
- 通道：输出通道、单色、RGB/常数权重、色彩噪声保护。
- 曲线：RGB/红/绿/蓝/亮度、直方图、控制点、黑白端点、数值输入、重置。
- 参数双击复位、数值直接输入、实时预览、防抖与过期结果丢弃。

### A5. 主窗口附属界面

- 界面设置：浅色/深色、中文/English、等线/微软雅黑 UI/系统默认。
- 存储与缓存管理：运行本体、pip Cache、Windows TEMP、IceHaloStack TEMP、当前发布目录、旧版 Build；统计、选择、打开、复制路径、安全清理。
- 性能与内存详情：Memory、Shared Node DAG、Async Output、Performance & Stability、Cache Policy、完整性能报告。
- 单图批量导出处理分支：各处理结果选择、独立命名与导出状态。

## B. 节点堆栈延时窗口（必须）

### B1. 三栏布局

- 左栏可滚动；中部节点画布；右侧实时预览与 Processing/Writing/总进度。
- 水平分隔条可拖动，但调整窗口或分隔条时不得重新执行图像处理。

### B2. 参考堆栈与分组

- 滑动窗口、中心窗口、累计堆栈、逐帧剔除。
- Mean/Maximum、窗口大小、步长、预计输出、参考输出帧、生成参考堆栈。
- 去闪、曝光平滑、白平衡平滑及状态。
- CPU/自动/CUDA、RAM 上限、性能策略与详情。

### B3. 流程管理

- 无限流程、启用状态、选择、新建、复制、删除。
- 保存当前预设、加载为新流程、批量导入预设。
- 全局 Undo/Redo 与节点弹窗局部 Undo/Redo。
- 预设与流程名称不丢失，禁用流程不参与批量导出。

### B4. 节点画布

- Stack、Stretch、Base、USM、BGR、High Pass、Emboss、BR、Output。
- 节点拖动、空白拖动平移、滚轮纵向、Shift+滚轮横向、Ctrl+滚轮缩放。
- Shift 拖拽连线、循环检测、删除/新建节点、U 形/纵向自动排列。
- 单击编辑、右键菜单、节点启用状态和执行顺序可视化。

### B5. 节点参数窗口

- Stack：显示并复用左栏分组参数。
- Stretch：启用、Strength、Black Point。
- Base：完整基础调色、白平衡吸管、Base Curve 及高级区域异步创建。
- BGR：Background 与 Curves 组合。
- USM：Amount、Radius、Threshold、1–10 次重复。
- High Pass：Radius、Opacity、Mode。
- Emboss：类型、角度圆盘、高度、数量、Blend、Opacity。
- BR/Channel：输出、单色、RGB/常数、噪声保护。
- Output：禁用/序列/视频/同时输出，序列与视频格式、临时序列策略、FPS、缩放、命名模板与流程名称。
- 所有参数窗口都支持应用/取消语义；取消必须恢复打开前状态。

### B6. 三种曲线编辑器

- Flow Curves、Base Curve、Standalone High Pass Curve。
- RGB/红/绿/蓝/亮度、直方图、添加/拖动/删除控制点、端点拖动、输入/输出数值、单通道/全部重置、应用/取消。

### B7. 实时预览与导出

- 25/50/100/200%、Fit、滚轮缩放、拖拽平移、Z Fit。
- 交互代理、快速代理、空闲 HQ 三条预览路径；拖动参数不得等待 HQ。
- 多流程批量导出、序列/视频、每流程独立命名、缩放、FPS、处理与写入进度、取消。
- 批量导出按钮的可用性必须只由真实前置条件决定，反复开关去闪/曝光/白平衡不得永久禁用。

## C. 曝光/白平衡关键帧工作区（必须）

- 去闪、曝光平滑、白平衡平滑、重新分析素材。
- 原始/修正后/左右对比，上一帧/播放/下一帧、FPS、时间线、缩略图带。
- 全帧表、蓝点关键帧切换、文件名和曝光/色温/色调修正值。
- 关键帧向导、生成/重置、同步当前调整到全部关键帧。
- 当前关键帧曝光、色温、色调、对比度、高光、阴影、白色阶、黑色阶。
- 原始/平滑趋势/关键帧目标三类曲线。
- 平滑力度、多遍平滑、应用关键帧并生成平滑过渡、再次平滑当前结果。
- 高级分析：去闪半径/强度、曝光和 WB 半径/强度/上限、关键帧影响、全画面/自动有效区域/自定义 ROI。
- 分析、过渡生成、预览解码与帧表更新必须异步、可取消、分批更新。

## D. 旧 TimelapseWindow 保留能力（必须合并，不单独复制旧窗口）

当前主入口已改为节点堆栈延时，但旧兼容类仍定义以下有效能力，WinUI 节点延时不能遗漏：

- 多输出组及其新增、复制、删除、启用。
- 每组独立预设、命名模板、序列/视频开关和缩放。
- 分阶段预览：拉伸、基础、Background+Curves、USM、High Pass、Emboss、Channel。
- 锁定当前处理方案后批量应用。
- 视频格式、分辨率、宽高比 Fill/Fit/Stretch。

## E. 非功能验收（必须）

- 正常前台 Release 窗口拖动、缩放、滚动和页面切换无 Tk 式拖影。
- `ICEHALOSTACK_SHOW_PERF=1` 记录 FPS、平均帧时、P95 与卡顿帧。
- 处理/写入期间仍能移动窗口、滚动、切换流程和取消。
- 列表虚拟化、页面复用、异步缩略图、进度节流、Dispatcher 批量更新。
- 自包含发布不携带完整开发 Python 环境、pip 缓存、旧 Build 或重复 Runtime。
- Windows 11 WinUI 包与未来 Windows 7 Classic 包分开发布。

## F. 完成定义

- 不存在用于弥补原生功能缺失的“完整经典工作区”按钮。
- 所有可达 Classic 功能都有对应 WinUI 入口、状态模型、Python 服务接口和自动测试。
- WinUI 前台逐项操作通过，输出结果与 Classic 对照通过。
- 文件规模测试通过，新增源码按职责拆分。
- 在这些条件满足前，不得宣布“完整迁移”或发布覆盖现有标签。
